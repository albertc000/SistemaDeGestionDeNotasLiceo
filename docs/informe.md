# Informe de nuestro Proyecto

El Liceo "Andrés Bello" ha llevado la Gestión de sus Notas de forma fisíca, lo que ha conllevado a dificultades a la hora de realizar dicho trabajo.

Es por eso que nuestro Proyecto intenta solventar esta problemática, con una Aplicación Web para la Gestión de las Notas, la cual contaría con 3 tipos de usuarios: Usuario Docente, Control de Estudio y Directivo.

El Usuario Docente es quien se encarga de subir las notas al sistema, correspondiendo a su o sus materias que imparte en sus secciones correspondientes. El Directivo es quien añade los estudiantes y profesores al sistema y quien los asigna en sus respectivos años y secciones (y materias en caso de los Profesores); y el Control de Estudio funciona como intermediario pudiendo tanto revisar la subida de notas de los estudiantes así como realizar reportes, boletínes y demas Documentos para la Gestión de Notas. El sistema contaría ademas con funciones tales como la muestra de estadísticas, filtrado, búsqueda y demás facilidades para el uso del mismo.
